# 🎂 우리가족 생일 알림

음력·양력 가족 생일을 달력으로 보고, 생일 3일 전·1일 전·당일에 알려 주는 휴대폰용 웹앱(PWA)입니다.
가족 정보는 서버로 보내지 않고 각 기기의 브라우저에만 저장됩니다.

## 주요 기능
- 양력 / 음력(윤달 포함) 생일 입력, 음력은 해마다 양력 날짜로 자동 계산 (1900~2050년)
- 달력·월별 보기, 다가오는 생일 D-day
- 3일 전 · 1일 전 · 당일 알림 (각각 켜고 끌 수 있음)
- **휴대폰 캘린더에 추가(.ics)**: 앞으로 10년치 생일과 오전 9시 알람을 캘린더에 넣어, 앱을 닫아 두어도 알림을 받을 수 있음
- 홈 화면 설치, 오프라인 실행, 백업/복원

## 휴대폰에서 쓰는 방법
서비스 워커와 알림은 **https 주소**에서만 동작하므로, 파일을 웹에 올려야 합니다. GitHub Pages를 쓰면 무료입니다.

1. 이 저장소를 GitHub에 push 합니다.
2. GitHub 저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소를 휴대폰에서 엽니다.
4. 홈 화면에 설치합니다.
   - 안드로이드(크롬): 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
5. 앱의 **알림·백업** 탭에서 알림을 허용하고 **테스트 알림**으로 확인합니다.
6. 확실한 알림을 원하면 **휴대폰 캘린더에 추가**를 누릅니다.

## 알림이 오는 방식
| 방식 | 안드로이드 | 아이폰 |
| --- | --- | --- |
| 앱을 열었을 때 | ✅ | ✅ (홈 화면에 설치한 경우, iOS 16.4 이상) |
| 앱을 닫아 둔 동안 | 🔸 크롬에서 설치한 경우 하루 한두 번 확인 (기기 상태에 따라 지연될 수 있음) | ❌ |
| 휴대폰 캘린더 알람 | ✅ | ✅ |

서버 없이 동작하는 웹앱이라 앱을 닫아 둔 동안의 알림에는 한계가 있습니다. 앱을 닫아 둔 동안에도 꼭 알림을 받으려면 캘린더 추가를 함께 사용하세요.
가족을 추가하거나 수정한 뒤에는 캘린더에 다시 추가해야 합니다. 같은 일정은 같은 UID로 만들어지므로 대부분의 캘린더 앱에서 중복 대신 갱신됩니다.

> 구글 캘린더 웹에서 .ics를 가져오면 파일 안의 알람 대신 구글 캘린더의 기본 알림이 적용됩니다.

## 로컬에서 실행
`index.html`을 더블클릭하면 모듈 로딩이 막혀 동작하지 않습니다. 간단한 웹 서버로 여세요.

```bash
npx serve .
# 또는
python -m http.server 8000
```
